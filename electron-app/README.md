# CourtVision desktop app

Electron + React + TypeScript interface for CourtVision. It starts the FastAPI server
(port 8765) itself and shows predictions, market lines, the report card and model metrics.

```bash
npm install
npm run dev         # development
npm run typecheck
npm run build:win   # Windows build
```

See the [main README](../README.md) for setup, data and models.
